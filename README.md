# React_JS - Learning Repository

This repository contains a collection of small React applications built as part of my learning journey. Each project focuses on different React concepts, from basic components and hooks to advanced topics like routing and API integration.

## 🚀 Projects Included

### 1. Installation and Setup
Basic React setup and configuration to get started with React development.

### 2. Practicing Components and UseState - Shopping Cart
A shopping cart application demonstrating:
- Component composition
- State management with `useState` hook
- Props drilling
- Event handling

### 3. React Routing App
Implementation of React Router for:
- Client-side navigation
- Dynamic routing
- Nested routes
- Route parameters

### 4. Task Manager
A task management application showcasing:
- CRUD operations
- State management
- Form handling
- Local storage integration

### 5. Axios API
Demonstration of API integration using Axios for:
- GET requests
- POST requests
- Error handling
- Loading states

### 6. News App
A news application built with:
- API integration
- Data fetching
- Component lifecycle
- Responsive design

### 7. React Simple Tasks Practice
Miscellaneous practice projects covering:
- Various React hooks
- Conditional rendering
- Lists and keys
- Forms and controlled components

## 🛠️ Technologies Used

- **React** - UI library
- **React Hooks** - useState and useEffect
- **React Router** - Navigation and routing
- **Axios** - HTTP client for API calls
- **Fetch API** - Native browser API for HTTP requests
- **CSS/SCSS** - Styling
- **JavaScript (ES6+)** - Core language

## 🚦 Getting Started

Each project is independent. To run any project:

1. Navigate to the project directory:
   ```bash
   cd apps/[project-name]
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
